# SystemSculpt 6.6.4

SystemSculpt 6.6.4 makes Chat activity easier to scan and explore.

- Reasoning and adjacent tool calls now appear in one compact activity drawer.
- Completed work uses clear labels such as `Reasoned`, `Read 4 files`, and `Searched 7 patterns`.
- Active work uses progress labels such as `Reasoning...` and `Reading 3 files...`.
- Each activity remains available inside the drawer with consistent icons, spacing, and ownership lines.

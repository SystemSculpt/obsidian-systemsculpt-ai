# SystemSculpt 6.2.3

SystemSculpt 6.2.3 keeps Studio image generation aligned with the current managed image service.

- Studio image nodes now expose only controls the managed service applies: Prompt, Image Count, and Aspect Ratio.
- Retired Seed and Image Size values are removed from existing Studio image nodes automatically.
- Image generation continues to use the latest managed engine without exposing provider configuration in the plugin.
- Streamed image downloads retain the strict file type, size, and integrity validation introduced in 6.2.2.

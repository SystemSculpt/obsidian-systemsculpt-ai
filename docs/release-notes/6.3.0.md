# SystemSculpt 6.3.0

SystemSculpt 6.3.0 moves managed chat to a server-owned streaming session and
makes web research activity clear in the conversation.

- Chat sessions now stream through the first-party SystemSculpt service while
  Obsidian remains the approval and vault-tool surface.
- Reconnects, queued turns, cancellation, approvals, and tool-result delivery
  remain recoverable across reloads and interrupted connections.
- Adjacent web searches appear in compact `Search the web (N)` groups.
- Expanded search groups show every approved query in its original order.
- Saved chats restore web-search groups without losing query details.
- Failed server searches are labeled as web-search failures, not vault errors.
- Release checks cover the production API target, thin-client boundaries,
  replay safety, mobile behavior, and supported Node and desktop platforms.

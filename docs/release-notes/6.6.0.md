# SystemSculpt 6.6.0

SystemSculpt 6.6.0 makes ChatView activity calmer, clearer, and more stable during long responses.

- Reasoning and tool calls now share one compact activity timeline.
- Active responses show a live `Working for` timer.
- Completed responses group activity inside one closed `Worked for` drawer.
- Earlier activity stays inside a closed `+N previous tool calls` drawer, with closed reasoning and tool detail drawers inside it.
- Final answers and Sources stay visible outside the activity drawer.
- Tool rows use compact status marks and clearer details without passive response tooltips.
- Streaming Markdown keeps stable rendered nodes, focus, selection, and interactive Obsidian content.
- Scroll anchoring keeps the current reading position stable as messages stream, drawers change, and embedded content loads.
- Cancelled responses keep one stable `You stopped after` presentation across live settlement and reload.

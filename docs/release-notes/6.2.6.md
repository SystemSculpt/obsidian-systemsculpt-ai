# SystemSculpt 6.2.6

SystemSculpt 6.2.6 fixes follow-up messages in chats that used server-side web search.

- Continuing a chat after a web-search turn no longer fails with "SystemSculpt rejected this request." The search call's record stays in your local history, but it is no longer sent in a form the service must reject.
- Mixed batches of server-run and vault tools keep sending back only the vault results.

# SystemSculpt 6.19.7

## Less repeated work in media uploads

Audio Processor, transcription and document uploads now share multipart recovery, retry and cancellation handling. Local staging no longer immediately reads back each file it writes; every chunk or artifact still passes size and SHA-256 checks before use. Existing interrupted uploads remain recoverable.

## Faster transcription recovery

Recovering a transcript checks its output folder instead of scanning every file in the vault, including when recordings live at the vault root.

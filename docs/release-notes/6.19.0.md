# 6.19.0

- Chat agents can make images and videos with SystemSculpt, whichever agent you chat with: SystemSculpt, Claude Code or Codex. Results show in the chat and save to SystemSculpt/Images and SystemSculpt/Videos.
- Chat agents can list, create, open, edit and run your SystemSculpt Studio workflows, and list their outputs.
- Image and video generation come with a SystemSculpt subscription.

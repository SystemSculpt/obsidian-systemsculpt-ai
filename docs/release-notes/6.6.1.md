# SystemSculpt 6.6.1

SystemSculpt 6.6.1 makes ChatView failures recoverable and easier to diagnose without exposing chat content.

- Partial assistant output now stays visible when a response fails.
- Failed responses show compact Retry and Copy report actions without an empty assistant row.
- Retry can recover in the same chat without leaving stale active content or locking the composer.
- Client incident reports now include bounded rendering, scroll, resource, transport, lifecycle, and failure evidence.
- Incident reports use canonical JSON, stay vault-local, and exclude prompts, responses, paths, tool payloads, conversation IDs, request IDs, and attachments.
- Copied report bytes remain exact after plugin reload, including storage-failure memory fallback.
- Failed response drawers stay closed, terminal animations stop, and scroll position stays stable.

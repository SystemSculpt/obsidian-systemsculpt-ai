# 6.19.3

- Your messages stay visible when hosted answers finish, even if the chat could not be saved locally. Earlier unsaved turns also stay visible during follow-up messages.
- A save failure now shows a warning to check the chats folder in Settings. Unsaved chats need a working folder and a successful save before they can survive a reload.
- Recovered chats keep their conversation link so saved history reconnects to the right conversation.

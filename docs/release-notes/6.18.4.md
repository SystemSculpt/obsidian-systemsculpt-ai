# SystemSculpt 6.18.4

- With semantic search on, notes that match both your words and their meaning rank above notes found only one way.
- Meaning results that take longer than 1.5 seconds are now blended in when they arrive instead of being dropped.
- Results reorder when meaning results arrive, unless you are already choosing one: a focused result, the pointer over the list, or a scrolled list keeps its rows in place.
- Searches no longer send stale or duplicate meaning queries while you type.
- Saved Claude Code and Codex chats write tool output, commands and errors with vault-relative paths and ~ for the home folder, so the file no longer holds your full vault path or user name.

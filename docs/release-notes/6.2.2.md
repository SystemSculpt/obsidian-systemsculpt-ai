# SystemSculpt 6.2.2

SystemSculpt 6.2.2 makes Audio Processor easier to find and lets you choose the note you want before processing begins.

- Open Audio Processor directly from the Obsidian ribbon. The icon uses Obsidian's native ribbon behavior, so you can reorder or hide it with your other ribbon actions.
- Choose Detailed note + transcript, Meeting brief, or Clean transcript. Your preferred default is remembered for both audio files and YouTube links.
- Meeting brief focuses on outcomes, decisions, action items, and open questions. Clean transcript produces readable paragraphs without a separate summary.
- SystemSculpt can use web search when current information materially improves an answer, with brief in-chat activity updates while it works.
- Selected PNG, JPEG, and WebP vault images are sent as real visual context. Unsupported, damaged, or oversized images now show a clear notice instead of disappearing silently.
- Temporary processing outages now show a friendly, retryable message instead of a raw service error.
- Automatic spoken-language detection, code-switching, YouTube processing, durable recovery, and linked transcript delivery remain available across every output choice.

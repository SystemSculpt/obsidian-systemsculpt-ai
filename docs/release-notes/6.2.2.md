# SystemSculpt 6.2.2

SystemSculpt 6.2.2 makes Audio Processor easier to find and lets you choose the note you want before processing begins.

- Open Audio Processor directly from the Obsidian ribbon. The icon uses Obsidian's native ribbon behavior, so you can reorder or hide it with your other ribbon actions.
- Choose Detailed note + transcript, Meeting brief, or Clean transcript. Your preferred default is remembered for both audio files and YouTube links.
- Meeting brief focuses on outcomes, decisions, action items, and open questions. Clean transcript produces readable paragraphs without a separate summary.
- Chat responses now keep one stable visual shell from the first streamed update through completed history, with calmer reasoning and activity presentation and no lingering "Continuing" state.
- Consecutive actions of the same kind are grouped into plain-language summaries such as "Read 3 files," while failures and approval boundaries remain visible.
- Response copying now uses a compact icon with accessible success or failure feedback that does not move the layout.
- Edit a previous message directly in the transcript and resubmit from that point. SystemSculpt explains when later messages will be replaced and preserves your bottom-composer draft.
- SystemSculpt can use web search and other server-executed tools when they materially improve an answer, with ordered in-chat activity updates that remain compatible with older plugin clients.
- Selected PNG, JPEG, and WebP vault images are sent as real visual context. Unsupported, damaged, or oversized images now show a clear notice instead of disappearing silently.
- Studio image generations now download and save reliably when delivery uses streamed transfer, while retaining file type, size, and integrity checks.
- Temporary processing outages now show a friendly, retryable message instead of a raw service error.
- Pull request checks now validate the compiled mobile plugin bundle plus narrow-pane, touch, keyboard, and accessibility-sensitive chat behavior in a fast deterministic Node 22 pipeline.
- Automatic spoken-language detection, code-switching, YouTube processing, durable recovery, and linked transcript delivery remain available across every output choice.

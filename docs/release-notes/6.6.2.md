# SystemSculpt 6.6.2

SystemSculpt 6.6.2 makes new releases visible inside Obsidian within about one minute.

- SystemSculpt checks for a published release at startup, every minute, and when the user returns to Obsidian.
- Each release gets one notice per app session, plus a persistent desktop status-bar action until installation.
- A manual `Check for updates` command gives explicit current, available, or unavailable feedback.
- Update checks use first-party static release metadata and never call the GitHub Releases API at runtime.
- Obsidian Community Plugins remains the only owner of download, installation, activation, and rollback.

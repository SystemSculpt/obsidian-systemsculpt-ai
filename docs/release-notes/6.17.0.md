# SystemSculpt 6.17.0

Keep going when your agent runs out, and Claude Code and Codex start on more machines.

- **Keep going when Claude Code or Codex hits its usage limit.** The chat says the limit was reached, shows the reset time when the agent gives one, and offers **Use SystemSculpt instead** so you can carry on. Nothing is sent to SystemSculpt until you choose it.
- **Claude Code and Codex are found when installed with nvm, Volta, asdf, fnm, bun or pnpm,** even when Obsidian doesn't see your terminal's PATH. On Windows, agents installed with npm now start reliably. A slow sign-in check no longer hides an agent you've been using.
- **Retry and edit work in long Claude Code and Codex chats.** They no longer fail once a chat has read a lot of files.
- **Codex uses your own default model and thinking level,** shown as **Codex default** in the chat. You can still pick a specific one.
- **A rejected license can be fixed from the chat.** The failed message offers **See plans**, and when you're out of credits, what you typed stays in the box.
- **The message box shows its focus once,** as one outline around the box instead of a second ring inside it.
- **Studio image generation is retired.** Your saved images and projects stay, and video generation still works.

Update through **Obsidian → Settings → Community plugins → Check for updates**.

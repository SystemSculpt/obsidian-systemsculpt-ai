# SystemSculpt 6.2.4

SystemSculpt 6.2.4 hardens Studio project persistence and managed image runs after three production incidents.

- Studio always opens project files it persisted, including managed image placeholders and files saved by other plugin versions; run readiness is still enforced when a graph actually runs.
- Entry points are treated as derived data: stale or version-skewed entry IDs no longer make a project unopenable, and OS junk files such as .DS_Store never invalidate project history.
- Failed managed image runs now report the service's specific failure reason instead of a generic "Managed job failed.", and transient polling errors are retried with backoff instead of failing the run.
- Text nodes connect to downstream text inputs, Chat renders server-executed tools, and the Audio Processor and managed agent surfaces are polished.

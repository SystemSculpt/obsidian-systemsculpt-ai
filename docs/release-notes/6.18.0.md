# SystemSculpt 6.18.0

Keep your agents working while you move between chats.

- **Switch chats without stopping Claude Code or Codex.** Open another chat, start a new one, or close the chat pane while a turn runs. The answer still saves to its original chat. Reopen it to see the live progress or answer an approval request. **Stop** still stops the turn.
- **Failed turns stay marked as failed after you reopen a chat or restart Obsidian.** Claude Code and Codex errors no longer look like successful replies after a reload.
- **Obsidian's chat header follows the chat title.** Renaming a chat updates the header without reopening it.
- **Coming with the iPhone app: run approved handoffs in your vault.** This release adds the desktop runner for iPhone handoffs, with progress and a link to the saved result in the chat. The iPhone app is not yet available.

Update through **Obsidian → Settings → Community plugins → Check for updates**.

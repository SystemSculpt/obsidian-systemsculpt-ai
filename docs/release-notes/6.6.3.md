# SystemSculpt 6.6.3

SystemSculpt 6.6.3 makes new plugin releases clear, inviting, and easy to install.

- Each new version now gets one polished update modal across desktop and mobile.
- The “Let's evolve” action opens the official SystemSculpt page in Obsidian Community Plugins.
- Dismissing the modal keeps the persistent desktop status-bar reminder without showing the modal again for that version.
- The manual `Check for updates` command can reopen the modal at any time.
- Obsidian Community Plugins remains the only owner of download, installation, activation, and rollback.

# SystemSculpt 6.2.7

SystemSculpt 6.2.7 makes managed chat follow-ups reliable after web search,
including chats first saved by older plugin builds.

- Reloaded chats no longer resend server-owned web-search history in a form the
  service rejects.
- A failed server-side search preserves its fallback response and no longer
  corrupts the next turn.
- Malformed or partially saved chat history now fails safely instead of
  inventing missing tool data.
- Editing an earlier message keeps vault-change confirmation safeguards even
  when saved tool metadata is malformed or reuses an identifier.
- Billing actions now accept only verified HTTPS SystemSculpt destinations.
- Local and hosted release gates now cover legacy reloads, request replay,
  streaming fragmentation, session fencing, mutation testing, Windows and
  macOS behavior, and supported Node versions.
- CI failure evidence is bound to the exact built plugin files, and mutation
  testing rejects targets that escape its isolated mirror.

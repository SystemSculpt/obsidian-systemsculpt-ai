# SystemSculpt 6.16.0

Fewer interruptions: SystemSculpt speaks up only when something needs you.

- **Fewer pop-ups and success messages.** When the result is already on screen, such as a changed setting, an opened note, a pinned file or a finished Studio run, no extra message appears. Copy buttons say **Copied** on the button itself.
- **Errors show once, where they happen.** A problem appears in the panel, dialog or settings row you were using, not again in a second pop-up.
- **No welcome or update pop-up on its own.** A fresh install opens nothing. A new release shows only a quiet **Update SystemSculpt** item in the desktop status bar, and **Check for updates** still tells you when a newer version is available. Signing in shows its result once, where you started it.
- **Not now for bulk transcription.** When several audio files arrive at once, **Not now** leaves them waiting, with nothing uploaded. Run **Resume inbox transcription** when you're ready.
- **Long chat titles no longer clip.** A long title shows its beginning and ends with an ellipsis.
- **Less work when opening chats and Settings.** Opening a chat creates one chat view, and Settings builds only the tab you open.

Update through **Obsidian → Settings → Community plugins → Check for updates**.

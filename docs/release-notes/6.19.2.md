# SystemSculpt 6.19.2

## Search results end cleanly

**Search** previews end on a whole line with an ellipsis, never a line cut through the middle. Each result shows its folder and when it changed; a long folder shortens, the date never does.

## Moves read at a glance

When an agent asks to move a note, the request says where it goes ("Move Launch plan.md to Press") and shows the full old and new paths, each on one line. In a narrow pane, approval buttons drop their keyboard shortcut glyphs.

## Studio text is easier to read

**Studio**'s card labels, status words and selected modes keep strong contrast in dark themes. Prompt fields keep an even inset and open on whole lines.

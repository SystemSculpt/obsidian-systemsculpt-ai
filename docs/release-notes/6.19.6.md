# SystemSculpt 6.19.6

## Reliable search pages

Vault search advances past unusually large matches with a clearly marked preview instead of repeating an empty page. Heavy result metadata no longer removes every match from a page.

## Cancel a Studio resize cleanly

A cancelled touch or pen resize restores the shape and releases its pointer listeners, so later project changes can refresh normally.

## Audio recovery stops on unload

Completed Audio Processor runs release their unload handlers. Queued recovery work does not start another run after the plugin unloads.

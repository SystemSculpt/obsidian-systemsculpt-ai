# SystemSculpt 6.14.0

Chat now uses your own Claude Code or Codex automatically, with Auto mode and inline approvals.

- **Start with the agent you already use.** On desktop, SystemSculpt detects installed, signed-in Claude Code and Codex and picks your most-used agent when you haven't chosen a provider and don't have a paid hosted plan. No SystemSculpt account is needed for your own agents. Paid hosted accounts and explicit provider choices stay in place.
- **Less setup, more progress.** New chats start in Auto unless you have chosen another native permission mode. Claude Code uses its native Auto safety checks, and Codex uses its native review with the vault's workspace sandbox. If Claude Auto is unavailable, the chat explains its Accept edits fallback. Hosted Auto handles ordinary note edits without asking; moves and deletions still need approval.
- **Review changes without leaving the conversation.** Approval requests now appear inline with a diff or request details. Press Enter to approve, Escape to deny, or Shift+Cmd/Ctrl+Enter to approve the available scope for the chat. Alt+Up brings the pending request into focus without interrupting your typing.
- **Know what is happening.** A compact summary shows the agent and permission mode. In-vault file paths stay vault-relative, external targets are marked clearly, and pending requests say “Waiting for your approval.” Use Change to choose a different provider or mode, or Detect again to refresh local-agent availability.

Your native agents still own their credentials, permissions and session history. Session approval is not a blanket permission bypass. Saved chats keep their own provider and permission choices; mobile continues to use hosted SystemSculpt.

Update through **Obsidian → Settings → Community plugins → Check for updates**.
